# BARCODE 0.0.0

### About
> Simple left-to-right barcode generator
> Supports Barcode 39, Barcode 93, Codabar, I2of5, UPCA, and UPCE.

### Output
> This is a Win32 executable (.exe)

### Dependencies
> This application depends on external dynamically-linked libraries (DLLs) in order
> to properly execute.
>
> | Dependency | Version |
> | ---------- | ------- |
> | GPH        | 0.603   |
> | UTIL       | 0.603   |
> | WIN        | 0.603   |
